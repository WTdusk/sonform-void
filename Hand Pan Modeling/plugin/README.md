# SONFORM: Void 0.9.4

开发者：**WTdusk**。项目采用 GNU AGPL-3.0-only，发布包包含许可证和对应源码。

七款物理建模打击音色。型号菜单和宿主的 Model 参数使用同一组名称。

| 音色 | 听感与演奏特点 | 音域 |
| --- | --- | --- |
| Orvane | 圆润的中心敲击，拍击和指节带来更明确的节奏轮廓 | F3–C5 |
| Gravik | 起始音区更低，适合有重量感的中心敲击与节奏型 | D3–A4 |
| Nuvora | 从较低的音区展开，可用拇指强调音头 | B2–F♯4 |
| Virel | 较高的音区，指尖音头清楚，适合旋律线 | C3–G4 |
| Serevin | 平击较平顺，边角击带有细碎的高频纹理 | D3–C5；边角击 A3–C5 |
| Tembrel | 舌鼓的钟鸣感；也可用止音奏法做短促节奏 | A2–E4 |
| Somera | 柔和指腹起音与自然共振，可在整个音域内半音演奏 | D3–C5 |

## 安装与使用

- Windows 安装程序可单独勾选 VST3 和独立版，并分别选择安装目录。VST3 自定义目录应是宿主会扫描的位置。

- VST3：把整个 `SONFORM Void.vst3` 插件包放到 Windows 的 VST3 插件目录，再让宿主重新扫描。
- 独立版：运行 `SONFORM Void 0.9.4.exe`，在 Settings 中选择音频设备和 MIDI 输入。
- 在音色菜单选型号，在奏法区域切换击法；也可使用屏幕键盘上标出的 MIDI 切换键。

0.9.4 可读取 0.9.3 的工程和预设。Granular Freeze 使用临时录音。重新打开工程或预设后，冻结会解除，继续演奏可重新录入。
